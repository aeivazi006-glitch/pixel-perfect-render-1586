## MODERNO storefront

Premium furniture e-commerce storefront (Vite + TanStack Start + Tailwind v4).

### Running in the sandbox

```sh
docker compose -f docker-compose.base44.yml up -d --build
```

The single `web` service runs the dev server from the cloned source on host port
3000. Dependencies are installed into a named volume on every container start
(`bun install --frozen-lockfile`), so a dependency change needs no image rebuild —
just restart the service. There is **no database or backend**: cart, wishlist,
recent searches and recently-viewed products persist in `localStorage` via
`src/lib/store.tsx`, and there are no migrations or seeds to run.

`docker compose ps` should show `web` healthy; `curl -sS http://localhost:3000/`
should return the rendered storefront HTML.

### Sandbox-only configuration

The dev server is reached through the preview proxy, which forwards a sandbox
hostname (`Host: <port>-<sandbox id>.$BASE44_SANDBOX_HOST_DOMAIN`) while the
browser sends the public origin. Both variables are supplied by the platform and
passed through bare in `docker-compose.base44.yml`:

- `__VITE_ADDITIONAL_SERVER_ALLOWED_HOSTS` — Vite ≥ 6.1 appends this to
  `server.allowedHosts`, which is what lets the proxied preview hostname reach
  the dev server. No `vite.config.ts` change is needed.
- `BASE44_PREVIEW_MODE` — available to app code for sandbox-only overrides. It is
  unset (or not `"1"`) everywhere else, and nothing in this repo currently
  branches on it. Any future override must compare against the exact string
  `"1"` so unset behaviour is unchanged. It must never be hardcoded to `1`, and
  it must never be used to weaken authentication, CSRF or TLS checks.

### Architecture notes

- **Content lives in one file.** All products, categories, testimonials,
  journal posts and shop-the-room hotspots are in `src/data/catalog.ts`, so the
  catalogue can be swapped for a CMS/commerce API without touching components.
- **Images** are bundled from `src/assets/moderno/` (real interior photography,
  no external hotlinking).
- **Storefront state** is a React context in `src/lib/store.tsx`
  (`localStorage` key `moderno-store-v1`). Promo codes: `WELCOME10`, `STUDIO15`,
  `MODERNO20`. Free shipping threshold is $100.
- **Routing** is file-based (TanStack Router). `src/routeTree.gen.ts` is
  generated by the Vite plugin on dev start — do not hand-edit it. Adding or
  removing a file in `src/routes/` regenerates it automatically.

### Verifying a change

- Frontend edits hot-reload in place; no restart needed.
- After changing `package.json` / `bun.lock`, restart the service:
  `docker compose -f docker-compose.base44.yml restart web`.
- Check for runtime errors in the browser console, and confirm
  `document.querySelector("#main")` has rendered children.
